Lab 02 helped me understand how HTML pages are structured. At first it was confusing trying to remember different tags and how everything fits together. After practicing more it started to make more sense. I learned how to organize a webpage using elements like header, main, and footer.

Lab 03 Reflection

In Lab 03 I started learning more about CSS and how styling works on webpages. I learned that CSS controls the way the page looks while HTML controls the structure. It took some trial and error to get things looking right, but it helped me understand how styling works.

Lab 05 Reflection

In this lab I learned how to make webpages responsive so they work on different screen sizes. Using flexbox and media queries helped the page switch between a single column layout on mobile devices and multiple columns on larger screens. This showed me how important responsive design is today since people view websites on many different devices.

One important design practice I learned is keeping layouts simple and easy to navigate. Using clear headings, consistent spacing, and a simple color scheme can make it a lot easier instead of trying to add all this fancy stuff that makes everything look stuffed together.
